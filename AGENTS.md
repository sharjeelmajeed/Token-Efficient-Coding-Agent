# Project instructions

This is the confirmed Token-Efficient Coding Agent hackathon project. Read
`docs/SCOPE.md`, `docs/STATUS.md`, and the original FSD before changing scope.
Keep it separate from other user projects. The FSD was confirmed on 2026-11-02.

Keep policy in the backend. No client or model can bypass ownership, locality,
budget, repository boundaries or exact-action approval. Never log secrets.
Never present mock provider counts as benchmark evidence. Tests are required for
security policy, persistence, budget races and side effects. All implemented APIs
must work; roadmap features belong in docs, not fake endpoints or placeholder UI.

Use the four human workstreams in `docs/TEAM_PLAN.md`. Do not create external
repositories, publish or post GitHub comments without the user's instruction.
Keep dependency versions locked and validate changes with the documented checks.
